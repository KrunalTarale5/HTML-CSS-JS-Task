🎬 Your mission: Movie night cards

Classes, ids and data attributes are how HTML talks to CSS and (later) JavaScript. The card look is already made in cards.css. You just need to use the right class names.

✅ You'll know it works when:

  • All four movies look like cards.
  • One card is golden with "Pick of the day" and one has a red NEW badge.
  • The "Jump to today's pick" link scrolls to the golden card.
  • In DevTools (right-click, Inspect) card 4 shows data-genre and data-year.

Tip: open the code, find each ✏️ TODO comment, write your code, save, then refresh the browser (or use Go Live). Tick the boxes as you go.

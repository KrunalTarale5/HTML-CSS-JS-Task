📐 Your mission: Navbar, hero and feature row

Flexbox arranges items in a row or a column. You will build three things that every website has: a navbar, a perfectly centred box and a row of equal cards.

✅ You'll know it works when:

  • Logo on the left, links in the middle, button on the right, all vertically centred.
  • The white box is centred both ways inside the blue hero.
  • Three feature cards share the width equally.
  • The tags wrap onto new lines when you make the window narrow.

Tip: open the code, find each ✏️ TODO comment, write your code, save, then refresh the browser (or use Go Live). Tick the boxes as you go.

🌈 Your mission: Style guide poster

Pick sizes, colours and fonts the professional way: rem for text, % and vh for layout, and a font with a safe fallback.

✅ You'll know it works when:

  • The three blue swatches look exactly the same (same colour written 3 ways).
  • The hero banner is 60% of the window height; resize the window to see.
  • The yellow box is exactly half the width of its parent.
  • Paragraphs have comfortable line spacing and never run too wide.

Readable text

Good text is easy to read. Use rem so the page respects the reader's font settings, a line height around 1.6, and never let lines run too long. About sixty characters per line is a comfortable limit for most people reading on a screen, so this paragraph will wrap at that width.

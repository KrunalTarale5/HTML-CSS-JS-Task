🧱 Your mission: Menu bar and badges

The display property decides how a box behaves: on its own line (block), inside a line (inline), or inline with a size (inline-block). This connects directly to what you learnt in HTML.

✅ You'll know it works when:

  • The menu is a horizontal row of purple buttons.
  • The red NEW badge has a fixed width.
  • Each "row" link is clickable across its whole width.
  • Box 2 vanished without a gap, Box 3 vanished but left a gap.

Tip: open the code, find each ✏️ TODO comment, write your code, save, then refresh the browser (or use Go Live). Tick the boxes as you go.

🧩 Your mission: Photo wall and page layout

Grid places things in rows and columns at the same time. Build a photo wall, a gallery that rearranges itself, and a classic page layout.

✅ You'll know it works when:

  • The photo wall has 3 columns and the first photo is twice as wide.
  • The coloured cards rearrange themselves when you resize the window (no media query!).
  • The page layout has a header and footer across the top and bottom, with a sidebar and main area in the middle.

Tip: open the code, find each ✏️ TODO comment, write your code, save, then refresh the browser (or use Go Live). Tick the boxes as you go.

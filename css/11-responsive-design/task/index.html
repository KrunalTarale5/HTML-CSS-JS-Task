📱 Your mission: Make it phone-friendly

The same page must look good on a phone, a tablet and a laptop. Work mobile first: write the small-screen layout first, then use media queries to add more columns as the screen grows.

✅ You'll know it works when:

  • On a narrow window (or phone view) the cards are stacked and the menu is a column.
  • From 600px wide you get two columns; from 900px wide you get three columns and a horizontal menu.
  • The big image never overflows the screen.
  • Test it: press F12, then Ctrl+Shift+M and drag the width.

Tip: open the code, find each ✏️ TODO comment, write your code, save, then refresh the browser (or use Go Live). Tick the boxes as you go.

🎫 Your mission: Ticket cards

Every element is a box: content, then padding, then border, then margin. Turn two plain text blocks into neat ticket cards.

✅ You'll know it works when:

  • Two cards, 300px wide, centred, with space between them.
  • Rounded corners and a soft shadow.
  • Open DevTools (F12), hover a card in Elements, and look at the coloured box diagram.

Tip: open the code, find each ✏️ TODO comment, write your code, save, then refresh the browser (or use Go Live). Tick the boxes as you go.
